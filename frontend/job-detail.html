Context & Mission

About the Role

Northstar Technologies powers telemetry brokers and continuous ingestion rails for sovereign edge networks. We are seeking an exceptional Senior Backend Engineer to own the core real-time streaming engine, currently processing 4.2 million events per second with strict p99 sub-15ms delivery guarantees across distributed multi-region clusters.

In this role, you will bridge systems-level partition replication with high-throughput consumer services. You will design, benchmark, and deploy zero-downtime schema evolution primitives, harden distributed consensus state machines, and ensure fault-tolerant event durability across unpredictable transit backbones.

Core Architectural Responsibilities

  • check_circle High-Throughput Partition Orchestration: Architect and optimize low-latency consumer groups and parallel partition workers in Go, Rust, or Python with explicit memory and garbage collection telemetry.
  • check_circle Consensus & Durable State Machines: Implement and extend Raft/Paxos-based log replication for dynamic cluster rebalancing and failover arbitration across heterogeneous availability zones.
  • check_circle Zero-Downtime Data Plane Migrations: Oversee Avro/Protobuf event contract registries and non-blocking streaming data schema migrations across multi-terabyte active topics.
  • check_circle Latency & Saturation Observability: Build automated synthetic probes and p99.9 latency telemetry pipelines feeding into our centralized telemetry broker.
  • check_circle Async Engineering RFC Authorship: Produce structured technical RFCs, conduct rigorous peer design reviews, and establish asynchronous architectural consensus before deploying code.
Mandatory Required Qualifications
  • 5+ years professional backend engineering with Go, Rust, or advanced Python runtime internals.
  • Deep mastery of Apache Kafka, Redpanda, or distributed append-only commit logs (partitioning, consumer group rebalancing, offset commits).
  • Proven foundation in distributed systems consensus (Raft, Paxos, Vector Clocks, leader election).
  • High comfort in an asynchronous, documentation-first culture with written RFC decision tracking.
Preferred Preferred Credentials
  • Hands-on experience with eBPF network trace analysis and kernel socket packet monitoring.
  • ClickHouse or DuckDB analytical streaming sink integrations.
  • Authoring and maintaining custom Kubernetes Operators for distributed stateful sets.
  • Open-source contributions to real-time stream processing engines or KV storage engines.
